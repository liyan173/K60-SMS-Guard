# K60 后台短信限制

适配 Redmi K60 Pro（22127RK46C，socrates）和 Android 16。安装包采用 KernelSU 的脚本模块格式。

## 安装与核验

1. 在 KernelSU 的「模块」里选择「从本地安装」，选中这个 ZIP，然后重启。
2. 开机后可通过 ADB 读取 `/data/adb/k60-sms-guard/last-boot.log`。日志会列出命中的后台发信权限、小米 SIM 卡激活服务的安装状态和 5G 消息开关。
3. 默认短信应用和系统电话的权限由 Android 继续管理。模块只按包名和 UID 限制清单内的后台服务。遇到额外的共享 UID 成员时会跳过该项。

模块按当前用户卸载系统预置的小米 SIM 卡激活服务，限制小米账号、查找设备等后台服务的发短信权限，并关闭 5G 消息及发送失败后的短信和彩信回落。系统自动生成的 `rcs_enable_cm` 组件选择标志由系统管理。

## 已有 K60 启动脚本

模块首次完整应用后，会把已知版本的旧启动脚本保存到 `/data/adb/k60-sms-guard/legacy-service-hook.sh`。KernelSU 移除模块时会尝试恢复该脚本，原路径如已有文件则保留备份。

停用模块会停止它在之后的启动中重新应用规则，Android 已保存的卸载与权限状态会持续生效。应用前的状态记录在 `/data/adb/k60-sms-guard/before.tsv`。恢复小米服务及其发信授权会重新带来短信激活的可能。
